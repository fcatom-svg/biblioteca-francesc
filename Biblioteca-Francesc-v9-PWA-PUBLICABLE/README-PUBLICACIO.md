# Biblioteca Francesc v9 — build publicable

Aquesta versió NO inclou la biblioteca personal incrustada.

## Primera posada en marxa
1. Publica aquests fitxers en una URL HTTPS estable.
2. Obre l'app publicada.
3. Importa el backup JSON exportat des de la v8/v9 anterior.
4. Configura OneDrive.
5. Després de confirmar la primera sincronització, OneDrive passa a ser la còpia al núvol.

## Important
- No publiquis cap backup JSON al repositori.
- No publiquis cap fitxer `biblioteca.json`.
- El codi de l'app pot ser públic; les dades personals no.
